# Escalation Matrix

| Situation | Priority | Escalate to | When |
|---|---|---|---|
| Single user, workaround available | P4 | Stay at L1 | Escalate after 60 min w/o progress |
| Single user, cannot work | P3 | L2 Desktop Support | After 30 min w/o progress |
| Multiple users affected | P2 | L2 / Network team | Immediately |
| Service-wide outage | P1 | Incident manager + L3 | Immediately |
| Suspected compromise (unexpected lockouts, malware) | P1 | Security team | Immediately, do not "fix" first |
| Needs admin rights/policy change you lack | Any | Owning team | After documenting diagnostics |

**Escalation note must contain:** user, device, exact symptom, steps already tried with results, evidence (screenshots/logs), business impact.
